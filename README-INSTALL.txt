SKELL SNAP - WINDOWS VST3 INSTALL

1. Extract the entire ZIP to a normal folder.
2. Double-click Install-Skell-Snap.bat.
3. Close and reopen your DAW, then rescan VST3 plug-ins.
4. Load "Skell-Snap" from the VST3 effects list.

The installer copies the complete Skell-Snap.vst3 bundle to your per-user VST3 folder:
%LOCALAPPDATA%\Programs\Common Files\VST3

No administrator permission is required. The installer does not remove or overwrite any other plug-in.

If your DAW does not scan the per-user VST3 location, add that folder to its VST3 search paths and rescan. As an alternative, copy the entire Skell-Snap.vst3 folder to:
C:\Program Files\Common Files\VST3
Windows may request administrator permission for that location.

Do not copy only the inner .vst3 module file. The complete Skell-Snap.vst3 directory is the plug-in bundle.
